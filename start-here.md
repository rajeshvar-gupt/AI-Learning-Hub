# Start here

Your first goal is to understand what you are trying to build. Installing many frameworks is not a prerequisite.

## Choose your route

| Your starting point | First action | Evidence before moving on |
|---|---|---|
| New to programming | Read the foundations note, then study Python variables, loops and functions | Explain and modify a short program without copying |
| Comfortable with Python | Take the diagnostic and check maths/data-analysis stages in the roadmap | Read a CSV, summarize values and explain your assumptions |
| Already building ML models | Review evaluation, leakage and reproducibility | Reproduce a held-out result from a clean environment |
| Interested in GenAI/agents | Learn APIs, evaluation and retrieval before adding autonomous actions | Show failures as well as successful answers |

## First study session: about 45–60 minutes

1. Read [AI foundations](notes/foundations/ai-landscape.md) for 15–20 minutes.
2. Answer the [diagnostic](assignments/AI-001/questions.md) without reading the solutions.
3. Compare with the [answer guide](assignments/AI-001/solutions.md); write one correction in your own words.
4. Open the [roadmap](roadmaps/ai-engineer.md) and choose your entry stage.
5. Inspect the [project catalog](projects/catalog.md). A project marked incomplete or needing repair is for review, not a ready-to-run lab.

## A useful study loop

Explain the concept → work through one small example → change an input → predict what changes → run/check → explain the difference. Keep a learning journal with date, concept, result and one unresolved question. This is stronger evidence than counting watched videos.

## Minimal working habits

Keep each project in its own folder. Read the README before executing code. Record the actual runtime and dependencies used. Use small distributable datasets while learning. Do not put API keys into code or Git commits. When an example fails, capture the error message and what you expected.
