# Python functions · Revision

| Concept | Example | Remember |
|---|---|---|
| Definition | def double(value): | Body runs when called |
| Call | double(6) | Supplies an argument |
| Return | return value * 2 | Sends result to caller and ends call |
| Default | def check(score, threshold=40): | Used if argument omitted |
| Local name | total inside a function | Belongs to that function call |
| No explicit return | Function reaches end | Result is None |
| List | scores = [] | Holds values in order |
| Append | scores.append(80) | Mutates list; returns None |
| Empty check | if not scores: | Handle before division/min/max |
| Import guard | if __name__ == "__main__": | Keeps interaction out of imports |

Separate reading input, validating it, calculating results and displaying output. Document what each function expects and returns.
