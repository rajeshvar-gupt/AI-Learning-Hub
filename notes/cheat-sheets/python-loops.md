# Python loops · Revision

| Tool | Meaning | Watch for |
|---|---|---|
| `for n in range(1, 4):` | Visit 1, 2, 3 | Stop is excluded |
| `while condition:` | Repeat while true | Ensure progress or an exit |
| `break` | Exit nearest loop | Summary after loop still runs |
| `continue` | Start next iteration | Statements below it are skipped |
| `total += value` | Accumulate | Initialize total before the loop |
| `count += 1` | Count accepted items | Validate first |
| `total / count` | Compute mean | Check count is nonzero |

For repeated input: read → check quit → convert → validate → accumulate → repeat.
A valid zero and no accepted input are different cases.
