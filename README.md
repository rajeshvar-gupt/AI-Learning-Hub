## Learning order

Beginner orientation → Python and Git → mathematics and statistics → data analysis and SQL → machine learning → deep learning → a specialization (computer vision, NLP or data science) → transformers, GenAI and LLMs → RAG → assistants, agents and agentic systems → automation, MLOps and deployment → capstones, interviews and career preparation.

The first release contains foundations and learning guides. Most subject modules remain planned. The [curriculum map](CURRICULUM.md) shows where every subject belongs; folders are added when they contain real lessons.
