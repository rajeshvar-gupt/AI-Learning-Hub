# LLM-001 · Worked solutions

1. Require a nonblank string answer and an array of real source-ID strings, with a documented unsupported-answer convention.
2. Reliability, privacy, task quality, resource usage and costs still matter. Maximum length says little about use of a particular fact.
3. Use representative mixed-language examples and independent reviewers; report per-language slices and ambiguous cases, not only an aggregate score.
