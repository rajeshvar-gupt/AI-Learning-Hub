# PY-001 · First-program practice

Prerequisite: [first Python lesson](../../subjects/python/00-introduction/01-first-program.md). Time: 25–35 minutes. Submit a `.py` file plus short answers. Use fictional profile details. No packages needed.

1. **Concept (2 marks):** State the types of `"45"`, `45`, `45.0` and `False`.
2. **Prediction (2 marks):** With 20 minutes daily for 6 days, what are weekly minutes and hours? Explain the formula before running.
3. **Coding (3 marks):** Print a study card for topic `Python`, 40 minutes per day and 3 days. Show total minutes and hours to one decimal place.
4. **Debugging (2 marks):** Why does `minutes = "30"; print(minutes * 2)` display `3030`? Correct it for arithmetic.
5. **Scenario (1 mark):** Has this profile program learned from student data? Explain.

Optional challenge: add a Boolean `completed_today` and show it on the card. Try zero study days and explain the output. Do not add input() until you understand conversion; fixed-input programs are sufficient here.

Rubric: credit correct reasoning, runnable code and output consistent with the stated inputs. Keep your prediction before the actual output so you can compare them.
