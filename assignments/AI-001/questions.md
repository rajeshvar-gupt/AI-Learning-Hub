# AI-001: Choose an approach

Level: beginner. Prerequisite: read the AI foundations note. Time: 20–30 minutes. Submit a short Markdown/text file with answers and reasoning. No code or external account is needed.

1. A college sends the same reminder two days before every assignment deadline. Does this require machine learning? Explain your simplest design. (2 marks)
2. A system learns from labeled messages to predict whether a new message is spam. Identify the training examples, input and target. (2 marks)
3. A chatbot writes a confident explanation with an incorrect date. What should you verify, and why is fluent text insufficient evidence? (2 marks)
4. System A always retrieves a document, summarizes it and stops. System B chooses a tool, checks its result and decides whether another tool call is needed. Compare their control flow. (2 marks)
5. A classifier scores 98% on the same rows used to train it. What can you conclude, and what evidence is still missing? (2 marks)

## Optional mini project

Design a course FAQ assistant on paper: list allowed data sources, three questions it should answer, two it should decline, an evaluation method and one action requiring teacher approval. Do not implement external actions yet.

## Self-assessment

8–10: proceed, but review any missing reasoning. 5–7: reread the relevant distinctions. 0–4: discuss each scenario with an example. These thresholds guide revision; they are not a qualification or placement prediction.
