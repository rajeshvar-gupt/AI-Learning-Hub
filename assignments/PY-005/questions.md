# PY-005 · Practice

Read [the file-handling lesson](../../subjects/python/01-fundamentals/05-files-and-score-storage.md). Use fictional scores and a temporary practice folder.

1. Explain the difference between r, x, w and a. Which protects an existing file from replacement?
2. Save 0, 50 and 100 to a new file and reload it. Predict count, total, mean, lowest and highest.
3. Try saving again to the same path. What should happen to its original contents?
4. Write a file with 70 on line 1, abc on line 2 and 90 on line 3. Predict the load result. Should the tool report a summary from only the valid lines?
5. Compare an empty file with a file containing a single blank line. What does each mean to this format?
6. Why validate before opening the save target? Does with make a write atomic? How would a missing parent folder differ from an invalid score?
