# PY-004 · Practice

Read [the functions lesson](../../subjects/python/01-fundamentals/04-functions-and-score-summary.md). Attempt these before opening the solutions.

1. Define double(value) to return twice its argument. Call it with 6 and print the result.
2. A function prints 12 but has no return statement. What is stored by answer = that_function()? Explain.
3. Define is_passing(score, threshold=40) for a valid integer score. Check 39, 40, and 60 with threshold 60. State what your function assumes about input.
4. In the project, enter abc, -1, 101, 0, 100, q. Predict the final count, total, mean, lowest and highest.
5. Explain why an empty list cannot follow the usual mean calculation. What should quitting immediately display? Does a single score of zero produce the same result?
6. Define count_passes(scores, threshold=40) using a loop. It should return the number of valid scores at or above the threshold without changing the list. Check [], [39, 40, 100], and [0, 100] with threshold 100.

Completion: run your functions, explain return versus print, and run the project's test command.
