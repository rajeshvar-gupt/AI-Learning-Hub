# Role-specific routes

All routes use the shared AI engineer roadmap through Python, maths/statistics and data analysis. These are learning designs, not promises of hiring eligibility. Job requirements vary.

| Goal | Emphasis after foundations | Portfolio evidence | Interview focus |
|---|---|---|---|
| AI engineer | ML, APIs, LLMs, evaluation and deployment | A bounded application with a testable service | Tradeoffs, integration and failure handling |
| ML engineer | Data pipelines, ML evaluation, serving and monitoring | Reproducible training-to-inference pipeline | Leakage, drift, reliability and model selection |
| Data scientist | Statistics, SQL, experiments, analysis and communication | Decision-oriented analysis with uncertainty | Assumptions, metric interpretation and experiment design |
| Computer vision engineer | Images, CNNs/vision transformers, detection and evaluation | Vision model with representative failure analysis | IoU, data splits, latency and domain shift |
| NLP engineer | Text processing, representations, transformers and evaluation | Text classifier/retriever with error categories | Tokenization, class imbalance and semantics |
| Generative AI engineer | Generative models, APIs and output evaluation | Application with explicit quality criteria | Evaluation, grounding and unsafe/invalid outputs |
| LLM engineer | Transformer foundations, adaptation and inference | Controlled comparison of prompting/retrieval/adaptation | Data quality, compute tradeoffs and context limits |
| AI agent developer | Tools, state, bounded loops and structured outputs | Single-agent task with recorded tool failures | Tool schema, validation and stop conditions |
| Agentic AI engineer | Planning, orchestration, state and task evaluation | Multi-step system with reproducible traces | Whether dynamic control is justified and how it fails |
| MLOps engineer | CI, containers, artifacts, monitoring and rollback | Model release pipeline with recovery procedure | Versioning, reproducibility and service reliability |
| AI researcher | Deeper maths, literature review and experimental design | Small replication/ablation with limitations | Hypothesis, baselines, confounds and evidence |

Agentic systems do not inherently require multiple agents. Start with one agent or a fixed workflow if that solves the task. Research-oriented work needs substantially more depth than the first curriculum release.
