# Role routes and portfolio evidence

| Role | Priorities | Hub evidence | Interview defense |
|---|---|---|---|
| Data analyst | Cleaning, SQL, charts and uncertainty | Sales analysis | Join cardinality, totals and sampling limits |
| ML engineer/data scientist | Splits, baselines, metrics and deployment contracts | Supervised lab and Iris API | Leakage, residuals, class support and artifact schema |
| CV engineer | Image contracts, CNN gradients and representative evaluation | Digits CNN, synthetic images and transfer lab | Shapes, learned kernels, dataset shifts and equal-baseline result |
| NLP engineer | Tokenization, sparse baselines and evaluation | Support classifier and attention | OOV behavior, macro-F1, source/author splits |
| GenAI/RAG engineer | Prompts, provider contracts, retrieval and evidence | Mockable adapter and retrieval lab | Schema versus truth; retrieval versus answer support |
| Agent/automation engineer | State, tools, stopping, idempotency and authorization | Runner, queue and mentor capstone | Tool scope, ambiguous sends, failure traces and rollback |
| AI trainer | Prerequisites, explanations, exercises and honest demos | All lesson/assignment pairs | Teach one example, debug one failure and explain limits |

Choose two substantial projects to defend rather than listing every topic as mastered. Preserve actual reports and permission/provenance notes. Keep private career/company plans out of public portfolio claims.
