# Computer vision primary references

Checked 2026-10-11. These references support the introductory module; no PyTorch execution is claimed. The runnable project uses the existing pinned NumPy/scikit-learn environment.

- PyTorch, [Conv2d reference](https://docs.pytorch.org/docs/2.14/generated/torch.nn.Conv2d.html): layer shapes, cross-correlation, stride and padding. Version 2.14 was the destination of the official stable documentation redirect when checked.
- scikit-learn, [load_digits reference](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html): bundled dataset interface. For provenance, inspect load_digits().DESCR in the installed version.

Lessons, exercises and the NumPy CNN are original instructional material. Online documentation may differ from the tested versions in requirements-ml.txt.
