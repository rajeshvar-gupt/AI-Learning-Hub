## How to choose

Start with a project whose inputs and outputs you can explain. If you are learning Python, work on basic file handling before a web app. If you know ML, ask whether an evaluation split exists. If you choose an advanced model, check whether your environment can support it before downloading large dependencies.

An incomplete project can be a useful design exercise, but it should not be assigned as a working lab until repaired and tested.
